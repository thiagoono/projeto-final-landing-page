# 📚 Livro Novo de Novo — Landing Page

Landing page desenvolvida como projeto final de um curso de HTML e CSS, com o objetivo de praticar a construção e a estilização de interfaces web a partir de uma referência visual.

O projeto apresenta a proposta visual de uma **plataforma fictícia de venda de livros usados**, chamada **Livro Novo de Novo**. A plataforma foi idealizada para este projeto e não representa um serviço comercial real.

🔗 **[Acessar a landing page](https://thiagoono.github.io/projeto-final-landing-page/)**

## 🎨 Sobre o projeto

A página foi desenvolvida a partir de uma referência visual criada com o **Google Stitch**, utilizada como inspiração para reproduzir a interface com HTML e CSS.

A proposta visual busca transmitir a experiência de uma plataforma de livros usados, combinando elementos associados a bibliotecas com uma apresentação moderna e organizada.

O conceito visual inclui:

- Paleta de cores inspirada em bibliotecas, com tons de bege, marrom, verde-escuro e branco.
- Organização do conteúdo em uma página única.
- Utilização de imagens e elementos visuais relacionados ao universo literário.
- Estilo minimalista, com foco na apresentação da plataforma fictícia.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo da página.
- **CSS3:** estilização, composição visual e organização dos elementos.

## 🎯 Objetivo do projeto

Este projeto fez parte do meu processo de aprendizado em desenvolvimento web, permitindo aplicar conhecimentos de HTML e CSS na construção de uma interface a partir de uma referência visual.

O desenvolvimento também proporcionou prática na interpretação de layouts, na organização de conteúdo e na reprodução de uma identidade visual utilizando tecnologias fundamentais da web.
